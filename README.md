# 💰 Expense Tracker

A full-stack **MERN Expense Tracker** that helps users manage their personal finances by tracking income and expenses in one place.

## 🚀 Features

- 🔐 User registration and login
- 🔑 Secure authentication
- 💸 Add, edit, and delete expenses
- 💰 Track income and expenses
- 📊 Dashboard with financial summaries
- 📈 View spending and transaction information
- 🗂️ Organize transactions by category
- 🕒 Track transaction dates
- 📱 Responsive and user-friendly interface
- 🔒 User-specific financial data
- ⚡ Fast and dynamic MERN-stack application

## 🛠️ Tech Stack

### Frontend
- React.js
- JavaScript
- Tanstack React Query
- Tanstack React Table
- Typescript
- HTML5
- Chakra UI
- Axios

### Backend
- Node.js
- Express.js
- REST API

### Database
- MongoDB
- Mongoose

### Authentication
- JWT (JSON Web Token)
